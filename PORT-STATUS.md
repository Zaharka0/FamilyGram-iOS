# Перенос Android → iOS

Исходная Android-реализация: `Zaharka0/FamilyGram-Android`, commit `0124c31333d96f88b630b3102e999c3dc5b771dc`.
База iOS: Telegram 13.1.1 из `upstream.json`. Код переноса находится в `overlay`, все точки интеграции публикуются в `scripts/family_port.py`.

## Проверяемая совместимость

- Бинарный `fg1` codec повторяет Java `DataOutputStream.writeUTF`, включая UTF-16 surrogate pairs, NUL и canonical URL-safe base64 без padding.
- `tests/fixtures/fg1-android-vectors.json` содержит **18** вариантов операций, созданных настоящим `FamilyCore.java` Android-проекта. Swift проверяет декодирование и обратное кодирование байт-в-байт.
- Логические часы, nonce, actor ownership, подтверждённые сообщения, дедупликация взносов и ходов, salted commit/reveal вопроса дня совместимы с Android.
- Reply-to сохраняет локальное соответствие ссылок на исходные сообщения: ID сообщения у двух собеседников может различаться.
- Локальная постановка сообщения на отправку не считается подтверждением сервера. Изменение общей карточки применяется только по подтверждённой истории.

## Различия платформ и ограничения проверки

- iOS не предоставляет публичный аналог Android `FLAG_SECURE`: покрытие скрывает экран при записи/трансляции и при сворачивании, но не может гарантированно запретить разовый скриншот.
- Python SDK общий, но Android Java/Chaquopy/Xposed API на iOS отсутствует. Плагины с такими вызовами требуют адаптации. Встроен тот же отключённый по умолчанию Heart signature. Плагины — доверенный код внутри приложения, не песочница; блокирующий native callback невозможно надёжно остановить. Watchdog возвращает отправку штатному пути один раз и отключает движок.
- Пропуск пауз использует Telegram waveform, когда он доступен, а не ExoPlayer PCM silence processor. Без waveform голосовое играет целиком.
- Виджет требует дополнительный App ID/расширение и доступную App Group при подписи AltStore. Приложение и виджет используют одну группу; фото и настройки разделены по реальным ID аккаунтов и очищаются при logout.
- Общие списки, календарь, закладки, копилка, счёт, альбом и статистика доступны и в семейных группах. Вопрос дня, игры пары, случайные реакции и совместный просмотр предназначены для личного чата пары.
- Карточки, медиа и статистика восстанавливаются из истории. Пока не закончено полное индексирование, экран сообщает о неполной истории. Секретные чаты, автоудаляемые и одноразовые сообщения не индексируются.
- Не-Hug операции скрыты в обычной ленте FamilyGram. Другой Telegram-клиент может показать транспортный текст; это не отдельный сервер и не удаление сообщений из Telegram.
- Наличие кода и зелёный unit test не доказывают правильность работы UIKit, подписи виджета, декодера голосовых или синхронизации на двух телефонах. Обязательные ручные проверки: ниже.

## Проверка на iPhone и Android

1. Установить новый IPA поверх прежнего с тем же bundle ID; сохранить Telegram-сессию.
2. На обоих устройствах выбрать друг друга как половинку. Создать пункт/событие на одном — изменить на другом.
3. Отправить emoji/NUL-free Unicode текст, закладку фото/видео и проверить переход к исходнику у обоих.
4. Ответить на вопрос дня в разном порядке; до второго ответа не показывать первый. Повторная синхронизация не дублирует ответы.
5. Завершить обе игры с ходами по очереди, перезапустить клиенты, повторить последний транспорт — ход/взнос не удваивается.
6. Подключиться к видео обоим, проверить пуск/паузу/seek, выход одного и таймаут отсутствия связи.
7. Проверить ghost receipts для семьи/половинки и остальных, отдельный фильтр историй, офлайн/онлайн и восстановление всех исходных исключений.
8. Проверить cover при записи экрана, переключении приложений и возврате; личный виджет скрывается.
9. Проверить WidgetKit на домашнем экране, фото, дни и выбор правильного аккаунта deeplink.
10. Установить Heart signature, включить движок, плагин и подпись в настройках. Служебные fg1 сообщения не изменяются. Проверить отключение при ошибке/долгом callback.
11. Проверить голосовой Opus через нативный плеер, очередь/позицию/паузы и видимость статуса прослушивания при ghost.
12. Проверить UI с крупным шрифтом, светлой/тёмной темой и записанными кадрами анимаций.

## Сборка и публикация

Ветка переноса: `feature/family-ios`, PR #1. Базовая версия main установлена пользователем на iPhone; новый порт ещё требует полной сборки и проверок выше. Проверки Python SDK/упаковки, Swift codec и реального Android/Swift reducer-журнала прошли на commit cfc5da9. Синтаксическая проверка Swift не заменяет полную компиляцию Telegram.

Для проверки IPA: Actions → iOS IPA (AltStore) → Run workflow → feature/family-ios. Артефакт FamilyGram-iOS-AltStore содержит IPA, SHA-256 и JSON. Публичный релиз не создаётся из тестовой ветки. После переноса проверенного кода в main ручная опция publish_release публикует только успешно собранный IPA с тегом familygram-VERSION-bBUILD; ежедневная проверка внутри приложения сравнивает и версию, и номер сборки.
